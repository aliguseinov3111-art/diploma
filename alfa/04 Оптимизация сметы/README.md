# Оптимизация сметы

**Актуальный файл:** `ТС ЕР исходник.xlsm` (в этой папке) — .xlsm, т.к. содержит
макрос кнопки-переключателя. При открытии Excel спросит «Включить содержимое» —
подтвердить.

Состояние листа «Смета ЕР (общ) »: последовательность работ упорядочена внутри
разделов; в ячейках «Примечание» — 529 единообразных ссылок `см. лист «X»`
(синие, рабочие гиперссылки); структурная чистка (УФ → 2 правила, объединения
шапки разъединены с сохранением вида, единый шрифт Calibri 9, имена → 5,
внешние связи 35 → 20). Параметры курс/дисконт — столбец **Q** (Q1:Q4).
Автофильтр `A13:Q1684`, шапка столбцов — строка 13, «Раздел №1» — строка 14.

**Кнопка «Смета: … (нажмите — сменить)»** (левый верх листа) циклом переключает
видимость по столбцу Q «Бранч-бук»: **ВСЕ → ККО → ИНФРАСТРУКТУРА → ВСЕ**. В режиме
ККО видны строки с тегом ККО (в т.ч. «ККО ?» и «ККО, ИНФРАСТРУКТУРА») плюс строки
с пустым Q (типовые работы, заголовки разделов); аналогично для ИНФРАСТРУКТУРА.
Итоги «Итого/ВСЕГО» **не пересчитываются** — всегда по полной смете (по решению).
Макрос: модуль `SmetaSwitch`, `ТС ЕР исходник — xlsx до кнопки-переключателя.xlsx`
в `00 архив/` — версия без макроса.

`00 архив/` — предыдущие версии и подходы: `ТС ЕР исходник — до применения
последовательности.xlsx` (состояние до 03.09.2026), `ТС ЕР — раздельно.xlsx`
(вариант Y, 01.09.2026) и черновые/промежуточные сборки (`Смета объекта.xlsx`,
`Шаблон сметы (ручная сборка).xlsx`, `v1 - PQ и отдельный справочник/` и т.д.).
История версий также хранится в git — не нужно создавать новые бэкапы с датой
в названии, достаточно закоммитить.
