# Power Query в «Смета объекта.xlsm» — уже настроено

`Смета объекта.xlsm` собрана с Power Query: данные «Работы» и «Материалы» тянутся
напрямую из `Справочники.xlsx`. Ручное копирование листов больше не нужно.

Требуется Excel 2016+ (у вас 2019 — подходит). При первом открытии Excel спросит
разрешение обновить данные / включить макросы — разрешить.

---

## Что внутри

| Элемент | Назначение |
|---|---|
| Запрос **`Работы`** | лист `Справочники.xlsx` → «Работы» → скрытый лист `спр_Работы` |
| Запрос **`Материалы`** | лист «Материалы» → скрытый лист `спр_Материалы` (отсортирован по группе) |
| Модуль **`Обновление_справочников`** | макросы обновления (см. ниже) |
| Именованные диапазоны **`мат_<ГРУППА>`** | источник зависимого списка материалов (`=ДВССЫЛ("мат_"&группа)`) |

Формулы в «Конструкторе»/«Смете» ссылаются на диапазоны `спр_Работы!$A$2:$A$6000`
и т.п. — **не на таблицы**, поэтому обновление PQ их не ломает.

---

## Ежедневное использование

1. Правки — только в `Справочники.xlsx` (листы «Работы» / «Материалы»),
   **добавление в конец**, без вставок в середину.
2. В `Смета объекта.xlsm`: **Разработчик → Макросы → `ОбновитьИзСправочника`**
   (обновляет PQ + пересчитывает + пересобирает диапазоны `мат_*` за один шаг).
   Либо вручную: Данные → Обновить всё, затем макрос `ПересобратьДиапазоныМатериалов`.
3. Проверить лист «Контроль» — всё «ок» / 0.

> Удобно повесить `ОбновитьИзСправочника` на кнопку: Разработчик → Вставить → Кнопка → на листе «Параметры».

---

## Если папку/файлы переместили

Путь к `Справочники.xlsx` зашит в запросах абсолютно. После переноса:

**Данные → Запросы и подключения** → двойной клик по `Работы` → **Расширенный редактор** →
в строке `File.Contents("...\Справочники.xlsx")` поправить путь. То же для `Материалы`. Обновить.

*(либо вынести путь в ячейку — см. вариант с `ПутьПапки` ниже).*

### Вариант с путём в ячейке (необязательно)

На листе «Параметры» в свободную ячейку впишите путь к папке со `\` на конце,
присвойте ей имя **`ПутьПапки`** (Формулы → Присвоить имя). Затем в обоих запросах
замените `"D:\...\Справочники.xlsx"` на:

```m
(try Excel.CurrentWorkbook(){[Name="ПутьПапки"]}[Content]{0}[Column1] otherwise "D:\diploma\alfa\04 Оптимизация сметы\") & "Справочники.xlsx"
```

## Резервный файл без Power Query

`Смета объекта.xlsx` — та же смета, но со справочниками, **встроенными копией**
(самодостаточна, PQ/макросы не нужны). Обновление вручную: скопировать листы
«Работы»/«Материалы» из `Справочники.xlsx` в `спр_Работы`/`спр_Материалы` с заменой,
лист материалов предварительно отсортировать по «Группа_материалов»,
затем макросом пересобрать `мат_*` (макрос можно перенести из .xlsm).
